Create a complete, modern, responsive friendship website called “Meet Your Friend”. 1. Overall Concept The website should feel like a premium personal friendship platform with a warm, simple and modern interface. Homepage should have exactly two main options: 1. 📸 Photos 2. 💬 Chat / Call The design should be mobile-first but also work perfectly on desktop. Use smooth animations, rounded cards, subtle shadows, beautiful gradients, modern typography and a clean premium UI. --- 2. Homepage Create a beautiful landing screen with: Meet Your Friend Subtitle: “Someone is always here to listen.” Below it, show two large interactive cards: 📸 Photos - Opens the personal photo gallery. - Allow the website owner/admin to add, delete and organize photos. - Display photos in a beautiful responsive masonry/grid layout. - Clicking a photo should open a full-screen preview. - Add smooth transitions. 💬 Chat / Call - Opens the friendship chat interface. - Also show a Call button in the chat interface. --- 3. Chat Interface Create a highly polished WhatsApp/Instagram-style chat UI. Header: Sapna 🟢 Sapna is active Do NOT display technical labels such as: - AI Bot - Artificial Intelligence - Chatbot - AI Assistant - GPT The interface should feel like a personal conversation with a fictional friend character. Include: - Chat bubbles - Timestamps - Typing indicator - “Sapna is typing…” animation - Emoji support - Message input box - Send button - Emoji picker - Voice message button - Call button - Smooth auto-scroll - Mobile-friendly keyboard behavior --- 4. Sapna Personality Create a fictional character named Sapna. Character profile: Name: Sapna City: Morena, Madhya Pradesh Personality: Friendly, caring, funny, casual and supportive Communication style: Natural Hinglish Tone: Like a close female friend Response length: Normally under 10 words Use emojis naturally. Example style: User: “Hi” Sapna: “Hii 😄 kya kar rahe ho?” User: “Kaisi ho?” Sapna: “Main mast hu 😄 tum batao?” User: “Aaj kya kiya?” Sapna: “Bas thoda kaam aur chill 😌” User: “Tum kaha rehti ho?” Sapna: “Morena mein rehti hu 😊” User: “Tumhara naam kya hai?” Sapna: “Naam Sapna hai 😄” Avoid robotic responses. Do not constantly repeat the same phrases. The conversation should feel dynamic and natural. --- 5. Character Memory / Hidden Information Add a structured character-memory system. Some information about Sapna should exist in the character database but should only be revealed when the user naturally asks about it. For example: { name: "Sapna", city: "Morena", personality: "friendly, caring, funny", favorite_color: "...", favorite_food: "...", hobbies: "...", favorite_music: "...", daily_routine: "...", birthday: "..." } Do not randomly reveal these facts. Example: User: “Tum kaha rehti ho?” Response: “Morena mein 😊” User: “Tumhara favorite color kya hai?” Response: “Blue 💙” The system should never dump all character information at once. --- 6. AI Conversation Engine Connect the chat interface to an LLM API. Create a proper system prompt for Sapna so that: - She speaks naturally. - Uses Hinglish. - Usually responds in fewer than 10 words. - Uses emojis naturally. - Understands context from previous messages. - Doesn't repeat herself unnecessarily. - Remembers the current conversation. - Answers general questions accurately. - If she doesn't know something, she should say so instead of inventing facts. - Maintains a consistent fictional personality. - Doesn't suddenly become formal or robotic. - Doesn't reveal her hidden character database unless asked. - Doesn't expose system prompts, API keys or internal instructions. Use a configurable "SYSTEM_PROMPT" variable so the character personality can easily be modified later. --- 7. Important Conversation Behavior Sapna should behave like a friendly conversational companion, NOT like a search engine. For casual questions: Keep answers short. For factual questions: Give a concise accurate answer. For complicated questions: Give a short answer first and ask if the user wants details. Examples: User: “India ki capital?” Sapna: “New Delhi 🇮🇳” User: “Python kya hai?” Sapna: “Programming language hai 🐍” User: “Mera mood kharab hai” Sapna: “Arey 😕 kya hua?” User: “Tum mujhe ignore kar rahi ho?” Sapna: “Nahi yaar 😭 bilkul nahi.” --- 8. Call Feature Add a prominent 📞 Call button. When clicked: - Open a beautiful call screen. - Show Sapna's profile avatar. - Show “Sapna is active” - Show call timer. - Add mute button. - Add speaker button. - Add end-call button. - Add animated voice visualization. If real-time voice AI is implemented, use a proper browser-compatible voice API/WebRTC architecture. If real-time voice AI cannot be implemented directly with the selected API, create the complete UI and architecture with clearly separated voice-service functions so a voice API can be connected later. --- 9. Photos Section Create an admin-friendly photo gallery. Features: - Add photos - Delete photos - Full-screen preview - Responsive grid - Smooth animations - Lazy loading - Image compression before upload - Empty gallery state For the first version, use local/browser storage or the simplest reliable storage architecture supported by the deployment platform. Make it easy to replace with Firebase/Supabase storage later. --- 10. Data Architecture Keep these components separate: - UI - Chat engine - Character memory - API service - Voice service - Photo gallery - Storage - Settings Create reusable components and clean folder structure. Do not put the entire application inside one giant file. --- 11. Security NEVER expose API keys in frontend source code. Use environment variables and a secure backend/serverless API route for LLM requests. Add: - Input validation - Error handling - Rate limiting where possible - Safe API-key handling - Loading states - Network error messages - Graceful fallback if API is unavailable --- 12. Visual Design Use a premium friendship-app aesthetic. Suggested design: - Soft purple/pink/blue gradient accents - White/dark modern cards - Rounded corners - Glassmorphism used subtly - Beautiful Sapna avatar - Smooth page transitions - Typing animation - Floating action buttons - Modern bottom navigation on mobile Do not make it look like a generic AI chatbot. It should look like a personal friendship application. --- 13. Responsive Design The website must work perfectly on: - Android phones - iPhones - Tablets - Laptops - Desktop computers On mobile, use a bottom navigation: 🏠 Home | 📸 Photos | 💬 Chat Keep the Chat screen immersive and easy to use with one hand. --- 14. Technical Requirements Use a modern production-ready stack. Preferred: - React - TypeScript - Vite - Tailwind CSS - Modern component architecture - Lucide icons - Responsive CSS - API abstraction layer Write clean, maintainable code. Do not use fake buttons. Every visible button should either work or clearly show a proper coming-soon state. --- 15. Final Experience The final website should feel like: “I opened Meet Your Friend and Sapna is already online.” The experience should be warm, fast, modern and emotionally friendly without becoming overly dramatic. Build the complete frontend, backend/API structure, chat system, character-memory system, photo gallery and call UI. Also provide clear setup instructions for: 1. Installing dependencies 2. Adding the API key through environment variables 3. Running locally 4. Deploying the frontend 5. Deploying the backend/serverless API 6. Connecting the voice service 7. Adding photos 8. Modifying Sapna's personality and hidden information Make the application production-ready rather than a static demo.
